# 📐 QRBuddy Vector QR Studio for Figma & FigJam

Zero-build Figma Community plugin that drops print-verified gradient vector QR codes (`figma.createNodeFromSvg`) directly onto any Figma or FigJam artboard.

## Local Test in Figma Desktop (30 Seconds)
1. Open **Figma Desktop** → **Plugins** → **Development** → **Import plugin from manifest…**
2. Select `plugins/figma-plugin/manifest.json`.
3. Open `https://qrbuddy.app` inside your workflow or trigger the plugin directly from the Figma actions bar (`Cmd + /` → `QRBuddy`).
